📖 使用步骤

  1. 打开 B站侠，点击选择视频，从系统中挑选视频
  2. 点击选择音频，挑选要叠加的音频文件
  3. 点击开始合并，等待进度条走完
  4. 完成后在相册中查看，或前往 Movies/BXia/ 目录
